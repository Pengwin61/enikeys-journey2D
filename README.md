# Enikey Journey — браузерный прототип

Изометрический экшен-рогалик про эникея в корпорации Monolith Corp по концептам из `concept/` и канону проекта `../enikeys-journey`: сцены, квесты, предметы, враги и формулы взяты оттуда. Пиксель-арт, неон, bloom, всё рисуется процедурно на Canvas 2D. Сборка и зависимости не нужны.

## Запуск

Открой `index.html` в Chrome, Firefox или Safari. Или подними локальный сервер:

```sh
python3 -m http.server 8080   # → http://localhost:8080
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD / стрелки (работают и на русской раскладке) |
| Атака | ЛКМ, удерживать |
| **Reject**: нажать вовремя — пуля летит обратно отправителю (+2 ⚡, слоумо); держать — блок −50% | Shift / ПКМ |
| Рывок с неуязвимостью | Space |
| Найти уязвимость: шанс 20% + 5% за skill, цель получает ×2 урона | Q (⚡3) |
| Работать над таской, говорить, обработать духа очереди, перехватить подбитый дрон, станции лагеря | E |
| Следующая таска в трекере | Tab |
| Активные предметы | 1–5 |
| Инвентарь · пауза · звук | I · Esc · M |

## Как устроено (по канону)

- **Рабочий день идёт по часам 09:00–18:00** (около 5,5 минуты). В трекере три таски NAX-xx из `quests_1.yaml` с наградами и дропом 1:1. Каждая привязана к устройству на этаже: ПК, принтеру, роутеру, кофемашине, проектору, ИБП, стойке. Неоновая нить ведёт к выбранной таске. Таски стоят времени и выгорания, энергию не тратят. Иногда из системника лезут баги и легаси-демоны. По этажу разбросаны отделы с инцидентами: войдёшь — двери закроются.
- **Овертайм (IDEAS.md).** После 18:00 свет горит через одну лампу, каждые 30 с случаются ночные инциденты, враги на 30% сильнее. Награды за таски ×1,5, выгорание ×2. В полночь охрана выключает свет, и день закрывается сам.
- **Лагерь — это сам ряд 7.** Место 503 закрывает день с отдыхом (энергия полностью, −15 выгорания, +30% здоровья). HR-терминал даёт отпуск (50 ◆, всё восстановить, −50 выгорания). Учебный терминал — онлайн-курсы (+1 skill за 40 ◆, раз в день). В IT-шкафу каждый день два предмета.
- **Ресурсы.** Энергия — боевой ресурс: тратится на Q и `sudo`; пополняется от убийств, Reject, защиты-перерыва, кофемашины (раз в день) и энергетика. HP, выгорание, золото, опыт и уровни (+10 HP за уровень), skill, удача — по канону. Выгорание выше 50% снижает урон, на 100% — конец.
- **Предметы меняют оружие.** Обжимка RJ45 — цепная молния по патч-кабелю. Отвёртка — каждый 3-й выстрел рядом с врагом превращается во вращение. Флешка с Linux — зажал ЛКМ, отпустил, и выстрел `sudo` пробивает всё насквозь. Ноутбук — дрон-ассистент повторяет выстрелы. Сертификат AWS — каждый 5-й выстрел тройной. Лицензия Windows — криты вызывают «синий экран» (оглушение). Мультиметр — Q дешевле и точнее. Кофейная кружка — +1 ⚡ за убийство. Грейд усиливает эффект.
- **Враги в тему.** Баги размножаются, если не закрыть их за ~4,5 с. Пули демонов и всех остальных можно отразить через Reject. Духов очереди лучше «обработать» через E, а не расстреливать: они устойчивы к пулям, а обработка даёт энергию. Подбитого дрона охраны можно перехватить через E, и 15 с он воюет за тебя.
- **Лут.** Предметы из `item.go` с шансом дропа + удача и грейдами от Обычного до Легендарного (множители ×1–×3). Пассивные дают skill, энергию или удачу. Активные (энергетик, кофе, антидепрессанты, термопаста, пластырь) лежат на клавишах 1–5.
- **Элиты** со второго дня: Senior Backend (тянет энергию), Senior Frontend (бьёт по выгоранию), SRE-инженер (всё сразу), QA Lead (находит твои слабости). За победу — пропуск к боссу.
- **Боссы.** На каждом этаже свой босс с несколькими фазами; доступ к нему открывают пропуска.
- **Буфер.** Первая смерть за забег — не конец: за самовыпуск платишь предметом, половиной золота или пропусками. Вторая — конец забега.
- **Мета-прогресс** между забегами хранится в localStorage.

## Структура

```
index.html, style.css   — интерфейс: HUD, трекер, лагерь, буфер, сцены
assets/keyart.png       — арт титульного экрана (копия из concept/)
src/core.js             — математика, изометрия, пиксельные примитивы, ввод
src/audio.js            — синтезированные звуки и музыкальный секвенсор (WebAudio)
src/data.js             — канон: предметы, квесты, элиты, этажи, ранги, сцены, реплики
src/sprites.js          — пиксель-арт из текстовых шаблонов
src/level.js            — генерация этажей по типам отделов, устройства, запекание пола и стен
src/entities.js         — игрок и ресурсы, враги и элиты, снаряды, дроп
src/boss.js             — боссы
src/render.js           — свет, ночь, bloom, сортировка по глубине
src/ui.js               — HUD, трекер, мини-карта, инвентарь
src/game.js             — дни, таски, лагерь, боссы, буфер, мета-сохранение
```

Параметры для отладки: `?autostart` (без меню и пролога), `?floor=2|3` (сразу нужный этаж с подходящим билдом), `?god` (бессмертие). Сбросить мета-прогресс: `localStorage.removeItem('enikey-journey.meta')`.
