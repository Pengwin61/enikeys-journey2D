# Monolith Corp — адаптация игрового бренда

Источник: `concept/monolith.png`. Геометрия интерпретирует знак из трёх башен и ступенчатое основание центральной башни. Мелкие сколы и фактура из концепта убраны для читаемости в игровом масштабе. Это чистый векторный мастер, а не вырезка презентационного листа.

Открой `assets/brand/index.html` для просмотра набора.

## Набор

- `monolith-mark-{amber,ivory,red,gray}.svg`: самостоятельный знак, 104×128.
- `monolith-lockup-{amber,ivory,red,gray}.svg`: знак, название и PEOPLE · DATA · PROGRESS, 520×128.
- `monolith-stencil.svg`: тёмная маркировка ящиков, 104×128.
- `monolith-badge.svg`: иконка пропуска, 160×224. Портрет условный.
- `monolith-banner.svg`: вертикальное знамя, 192×448, заготовка для окружения.
- `monolith-terminal.svg`: экран корпоративного терминала, 320×200, заготовка.

Все SVG имеют прозрачное окружение. Панели, бейдж и знамя содержат собственную подложку. Экспортированные надписи состоят из векторных контуров и не зависят от веб-шрифтов. Свечение добавляется при использовании, а не запекается в знак.

## Подключено в игре

- Полный логотип с девизом: главное меню, HUD над мини-картой, пауза и переход между этажами. Знак также используется у обозначения отдела и в favicon.
- Стенные вывески используют готовые горизонтальные SVG-логотипы с контурными буквами: янтарный вариант в офисе, красный у боссов. Логотипы загружаются до генерации этажа, включая `?noart`. Вывески занимают до шести секций стены; цвет отражения на полу соответствует логотипу.
- Логотипы на стенах рисуются в разрешении экрана, отдельно от пиксельной подложки и размытого bloom. Маска секций стены сохраняет сортировку по глубине и затухание при перекрытии игрока.
- Ящики и корпуса HR/EDU-терминалов: небольшие накладные знаки. Для `painted` — векторная отрисовка, для `pixel` — тот же силуэт через пиксельный растеризатор. Исходные PNG не меняются.
- Процедурная графика (`?noart`) тоже получает маркировку.
- Корпоративный бейдж в инвентаре и карточке лута.

Знамя и полный экран терминала пока доступны как отдельные ассеты; они не заменяют существующие спрайты предметов. Силуэт на корпусе терминала сохраняет цветную индикацию HR/EDU. Вывески на подходящих длинных стенах стартовой комнаты гарантированы при генерации.

## Изменение и пересборка

Геометрия, палитра и Canvas-отрисовка: `src/brand.js`. Экспорт SVG и контуры букв: `scripts/build-brand.cjs`.

```sh
node scripts/build-brand.cjs
```

Команда воспроизводит 12 SVG без сторонних библиотек. Галерея и документация остаются отдельными файлами. Вывески используют SVG напрямую; маркировка предметов рисуется из общего векторного мастера. Если SVG недоступен, вывеска использует процедурный горизонтальный вариант.
